# Comic-Book-Collaboration-Analysis
Analyzing Marvel Comic Book Penciler/Writer Collaborations utilizing Excel and Tableau
Project Overview

This project explores collaboration patterns between comic-book writers and pencilers to better understand how creators work together across comic-book issues.

Objectives

Analyze collaborations between writers and pencilers.

Identify creators and creator pairs with frequent collaborations.

Compare solo work with collaborative work.

Present findings through data visualizations.

Tools Used

Microsoft Excel — Data organization and analysis

Data cleaning and transformation

Tableau Public — Data visualization and dashboard development

Data Preparation

The dataset was cleaned and prepared for analysis using Excel. Tasks included finding null values, removing duplicate writer/ penciler names, extracting issue numbers from issue titles, and organizing writer and penciler names for collaboration and solo analysis, remove columns from original Marvel Comics dataset that are unrelated to the thesis.

Analysis

The project examines creator collaboration patterns and compares solo contributions with collaborative work. Visualizations were developed to communicate the results clearly.

Key Findings

Jack Kirby/Stan Lee had the most collaborations at 86 total collaborations. Ron Frenz and Tom Defalco had the second most total collaborations at 58. John Byrne had the highest solo number, doing solo work on comics a total of 40 times. Jack Kirby had the highest Issue Count, at 66 total issues. John Byrne had the highest solo Issue Count at 33. The Amazing Spider-Man Annual had the longest Issue Duration at 54 years. The Incredible Hulk had the second longest Issue Duration at 37 years. The Amazing Spider-Man Annual also had the longest solo Issue Duration at 54 years. The Amazing Spider-Man Annual had both collaborations and solo work done on this issue over the 54 year span.
